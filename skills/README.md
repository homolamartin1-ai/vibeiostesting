# Skills — you build these here (Section 5)

This folder starts **empty on purpose**. **Section 5 is the centerpiece**: you build four
reusable AI Skills here with the agent, then reuse and sharpen them for the rest of the
course. Prompts are in [`../prompts/section-05-skills.md`](../prompts/section-05-skills.md).

The four skills you create:

1. `test-case-design.md` — feature → test matrix
2. `test-authoring.md` — test cases → clean tests (per framework)
3. `bug-reporting.md` — a failure → a developer-ready report
4. `flake-triage.md` — real bug vs. flaky test

> Your instructor builds these live and shares them as the class answer key — build your
> own first. These are living documents; yours will grow past any reference.
